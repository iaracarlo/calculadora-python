# Calculadora usando o PYTHON!
Nesse projeto você encontra as principais operações matemáticas e também a tabuada do número escolhido por você.
## Funcionalidades:
- ADIÇÃO
- SUBTRAÇÃO
- MULTIPLICAÇÃO
- DIVISÃO
- TABUADA de um número de 1 até 10
## Para esse projeto, utilizei as seguintes tecnologias:
- Python 3
- for
- if/elif/else
- input()
- f-strings
- Operadores matemáticos
## Como executar:
1 - Instale o Python 3
2 - Clone esse repositório
3 - Abra o arquivo calculadora.py
4 - Execute o programa pelo terminal ou pela sua IDE.

## OBJETIVO:
Este projeto foi desenvolvido como parte dos meus estudos em Python e lógica de programação, com o objetivo de praticar estruturas condicionais, entrada de dados, operações matemáticas e estruturas de repetição.
