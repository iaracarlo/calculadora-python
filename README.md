# Calculadora usando o PYTHON!
Nesse projeto você encontra as principais operações matemáticas e também a tabuada do número escolhido por você.
# Funcionalidades:
- ADIÇÃO
- SUBTRAÇÃO
- MULTIPLICAÇÃO
- DIVISÃO
- TABUADA de um número de 1 até 10
# Para esse projeto, utilizei as seguintes tecnologias:
- Python 3
- for
- if/elif/else
- input()
- f-strings
- Operadores matemáticos
# Como executar:
Instale o Python 3 <br>
Clone esse repositório <br>
Abra o arquivo calculadora.py <br>
Execute o programa pelo terminal ou pela sua IDE. <br>
